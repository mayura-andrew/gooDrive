A minimalist command-line interface for Google Drive. Built with Go for speed, simplicity, and elegance.

Quick Start

1 Install gooDrive
go install github.com/yourusername/gooDrive@latest
2 Authenticate with Google
goodrive auth
3 Start using gooDrive
goodrive list
goodrive download myfile.pdf
goodrive upload document.txt
