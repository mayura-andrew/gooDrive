🚀 Google Drive CLI

Access, sync, and manage your Google Drive from the command line

✨ Features

📥 Clone Files

Download files and folders from Google Drive with a simple command

📤 Upload & Sync

Upload local files and keep them in sync with Drive

📋 List & Browse

Browse your Drive files directly from the terminal

🔄 Push & Pull

Git-like workflow for managing Drive files

👀 View Contents

Preview file contents without downloading

🗑️ Delete Files

Remove files from Drive with confirmation

📦 Installation

From Source

git clone https://github.com/yourusername/gooDrive.git cd gooDrive go build -o drive main.go

🎯 Quick Start

  1. Set up your OAuth credentials (oauth.json)
  2. Run any command to authenticate
  3. Start managing your Drive files!
./drive clone <file-id-or-link>

📚 Available Commands

  • clone - Download file or folder from Google Drive
  • add-remote - Upload local file to Google Drive and track it
  • view-files - List files in Google Drive with filters
  • ls - List files in current Drive directory
  • status - Show status of tracked files
  • pull - Pull latest changes from Drive
  • push - Push local changes to Drive
  • rm - Remove file from Drive
  • cat - View file contents without downloading

🔐 Authentication

The CLI uses OAuth2 for secure authentication. On first run, it will:

  1. Start a local server on port 8080
  2. Open your browser for Google authentication
  3. Save credentials for future use
